# Learn Rust Basics

## Goals

- Understand variables, mutability, and shadowing
- Learn primitive types and function syntax
- See ownership and borrowing in action
- Practice with structs, enums, and iterators

## Quick start

Run the examples created in `src/basics.rs`:

```bash
cargo run -- basics
```

## Exercises

- Change the `add` function in `src/basics.rs` to handle `i64`.
- Add a `Point::distance` method that computes distance to another point.
- Modify the vector example to iterate by reference and preserve the vector.
